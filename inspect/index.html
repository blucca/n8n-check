Get the saved evidence.
  1. For the parent, save the JSON response from GET /api/v1/executions/<id>?includeData=true using your local API client.
  2. Follow saved metadata.subExecution.executionId references. Once-mode calls store them on the task; each-mode calls store them on returned items.
  3. Save each child's complete API response. Follow nested calls, then select all the files together above.
Workflow exports describe the workflow. This inspector takes saved execution responses, including workflowData and data.resultData.runData.

    
Collect from a parent ID.
Already have Node.js 24+? Download the local collector into your working folder. Set N8N_API_KEY in your local environment, then replace the instance URL and parent ID:
node n8n-fetch-bundle.cjs \
  https://your-n8n.example 123 \
  ./temp/saved-call-123
The GET-only script follows the saved child IDs. Use a fresh output directory, then choose its execution-*.json files above. If you select manifest.json too, the inspector keeps that acquisition receipt separate from execution data.
