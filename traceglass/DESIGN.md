# Traceglass visual direction

Audience: an n8n release engineer checking a saved parent-child boundary with an agent. The subject is a split source relationship: the memorable element is a lens-like, two-lane provenance diagram whose links reveal recorded versus derived roots.

Palette: porcelain #F6F9FC, navy #152B4B, mist #DAEAF3, cyan #007E9C, mismatch red #B13A35, consistent teal #197963. Color identifies evidence states. Typography: Barlow Semi Condensed for compact diagram nodes and headings; Atkinson Hyperlegible for descriptions and inspectable coordinates.

Layout: a compact case switcher above a 70/30 split canvas and raw inspector; selected terminal item anchors the graph and raw pointers. An Agent-Native sidebar acts on that same selected item. At mobile width, diagram, inspector, and agent controls follow in that order. Labels use sentence case.

```
Traceglass                Original / Repair / Missing
Caller roots  ───  Child terminal    | Raw pairedItem
 0  1  2  3       selected item      | Exact pointer
Recorded / derived links            | Source export
                     Shared agent panel
```

Plan review: a cream/serif report and mono eyebrow labels would resemble unrelated generic work. Cold porcelain, human-readable coordinates, and the paired-source lens instead follow this debugger's real subject. Keep surfaces quiet; interaction highlights the one selected relationship.
