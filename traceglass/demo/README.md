# Traceglass demonstration

[Public Clips demonstration](https://clips.agent-native.com/share/h9rFwycHkUD2) · [Recorded application video](traceglass-demo.mp4) · [English captions](traceglass-demo.vtt)

Real browser operations: select a saved terminal, inspect its source, ask the model to focus and audit the repair, download the dossier, and check a missing child export. Edits hold recorded frames for pacing and preserve the action sequence.

The example uses synthetic recorded n8n executions. English narration is synthesized with Amazon Polly Joanna. The pre-existing MIT audit and fixtures, and this event’s new Agent-Native app, are identified in the [project README](../README.md).
