Make it your case.

  1. After a known-good run, pin your input and transformation result, then export the workflow.
  2. Import it. Select those same nodes, then enable Stop after selected output.
  3. Review the case, download the pack and run sh run.sh in its extracted folder with Docker running.

The selected Code node runs; this branch stops before Slack. Other branches reachable from the fixture keep their own input and integration requirements. The original export stays unchanged.
