Execution gives null.

A reported task on n8n 2.46.7 has error text in the expression preview, then msg: null from executed Edit Fields. With your connected export and finished execution, make that symptom a one-item acceptance check:

  1. Copy the actual upstream start JSON item from the finished execution. Import the connected export; choose start as Fixture boundary. Enter that item as a one-object JSON array in Input items.
  2. Choose Edit Fields as Output to preserve and enable Stop after selected output.
  3. Choose Selected field + item count. Set Field path to json.msg and Expected item count to 1. For agreed text Validation failed, Expected output is an array containing one string:
["Validation failed"]
  1. Set n8n version to run to your execution's release. The reported task uses 2.46.7; the builder defaults to 2.41.7.

The execution supplies the input. Your required result supplies the expected text. Rerun the fixture after an expression change.
