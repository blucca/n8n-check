# Independent semantic canaries: a frozen twenty-execution n8n experiment

Preparation only, 2026-11-18, round 664. Native executions and network requests are
currently **0**. Root reviews and freezes this corpus before running it. This is
a new-input experiment, not a rerun of round 616's 36 executions, an inline or
Builder bridge, a Gemma pilot, a new SDK, or owner adoption.

## Three independent rules

`canaries.mjs` has three ordinary business-rule functions:

- `scoreEligible(row)`: numeric score ≥ 0.7.
- `expectedIDs(items, contract)`: one ordered output identity per eligible input
  occurrence, with explicit literal-whitelist/current-source rules in the two
  lawful semantic counterexamples.
- `expectedLeads(items)`: lowercase valid business email, group by mailbox
  ignoring case/+tags, keep the first row's already-canonical Full Name and the
  order of first appearance. This fixture family has no Gmail addresses, titles,
  padding, ambiguous names, email typos, sorting, or external lookups.

Answers use only the new business input and the frozen independent contract.
Workflow implementations, old cases, pin data and observed output tables supply
**0** expected values. Frozen original READMEs and exact quotations are in
`source-manifest.json`. The new `source`/`marker` diagnostic declarations belong
to our synthetic acceptance contract; they are not external user authorization.

## Keep the three verdicts separate

- **Relation** compares only declared ordered output fields, after transporting
  input identities through the frozen bijection, or after a declared diagnostic
  `source` perturbation. Unmapped outside constants remain unchanged; they can
  satisfy rename alone. Always-empty output can also satisfy it. A first-ID
  broadcast can covary, as shown by a pure assertion; an independent anchor or
  the existing partition method handles its defect.
- **Domain membership** tests identity range against **all input identities**,
  including ineligible rows. For leads this domain is every lowercased input
  `Email`, before mailbox deduplication. This weak independent range condition
  catches an outside constant. Input-occurrence overdraw is recorded separately;
  it does not change the range-membership verdict.
- **Anchor** uses existing n8n case `count` / `pluck` / `equals` assertions, with
  answers generated by the independent rules. Count, ordered projection and
  exact identity multiplicity are also displayed separately. An inside literal
  may pass range membership while violating multiplicity and identities.

Dynamic `processedAt` and legal diagnostic echo fields stay outside the
projection. Missing declared fields fail. ID whitelist/lookup/sort semantics
close rename scope; genuinely meaningful source fields close noise scope.
HTTP and joint external rename tests are outside this experiment.

## Prepare, freeze, run

No package installation is needed for preparation; Node.js 24+ is sufficient.

```sh
cd temp/round664/semantic-canaries
node canaries.mjs
node check-canaries.mjs
```

The pure check uses ordinary assertions and existing case validation and graph
preparation. It executes no workflow Code node and no n8n command.
`source-manifest.json` hashes code, unchanged existing core, source exports,
README evidence, contracts, fixtures, cases and the plan. Generation is
deterministic; the manifest excludes generated run output and itself.

After root's independent review and freeze, use the **existing** n8n binary:

```sh
node --max-old-space-size=128 run-native.mjs /absolute/path/to/existing/n8n
```

The runner verifies all manifest hashes, then reuses unchanged
`prepareWorkflow`, `runtimeEnv`, `command`, `executionFrom` and
`executionChecks`. It imports once and executes serially, with 60-second stages,
512 MiB child heap and a fresh private home. It saves prepared exports,
preparation metadata, raw CLI commands, full executions, every node's JSON main
outputs by port, actual business rows, and separate relation/domain/anchor
columns. `state.json` reports attempted/completed executions and a concrete stop
reason. No provider, HTTP mock, CSV or Google Sheets operation is introduced.

Source licenses and attribution are preserved in `sources/` and the root
`LICENSE`; existing core's `package.json` is retained for `version.mjs`.
